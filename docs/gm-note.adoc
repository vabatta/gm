== NAME

gm-note - format of a gm memory note file

== SYNOPSIS

_DIR_*/notes/*_ID_-_SLUG_.md*, where _DIR_ is *.memory* or the *gm.dir* of *.gmconfig* (see *gm*(1))

== DESCRIPTION

A note file is UTF-8 text. It starts with a header between two lines that hold
only *---*, followed by the body. *gm save* writes the file, and nothing edits it
afterwards. *gm* also reads files with CRLF line ends.

== FILE NAME

_ID_ is the UTC creation time as _YYYYMMDD_*T*_HHMMSS_*Z*, a hyphen, and 6
random hex characters, for example *20261114T174452Z-ef6552*. The random part
keeps ids unique when agents on different branches save in the same second. The
time part makes the files sort by creation time.

_SLUG_ is the title in lowercase, with each run of characters other than *a-z*
and *0-9* replaced by one hyphen, cut to 48 characters.

== HEADER

One *key: value* per line, in this order. *gm save* leaves out an optional key
when it is empty.
A reader ignores keys it does not know.

*id*:: The note id.
*type*:: *decision*, *lesson*, *fact* or *retirement*.
*title*:: The title as a JSON string, for example *"Cache uses Postgres"*.
*topic*:: Optional. A key without spaces, such as *decision/cache-store*.
*keywords*:: Optional for a retirement. Search words separated by spaces.
*at*:: Optional. A list of anchors. See *ANCHORS*.
*supersedes*:: Optional. A list of the ids of the notes this note replaces.
*created*:: The creation time in RFC 3339, UTC.
*migrated*:: Optional. Where an imported note came from, for example
  *engram obs-1a2b (decision)*.
*format*:: Optional. The version of this file format. A note without it is
  format 1, which this page describes, and *gm* writes format 1 without the
  key. A reader refuses a format it does not know instead of misreading the
  note. *search*, *show* and *list* then leave the note out, and *gm lint*
  fails with _FILE_*: note format* _N_ *needs a newer gm*.

*gm* writes a list as *[a, b]*. When an item holds a comma, a bracket, a double quote,
or a leading or trailing space, *gm* writes the whole list as a JSON array
instead.

== BODY

The body is one section per heading of the note type, in this order:

[horizontal]
*decision*:: *+## Decision+*, *+## Why+*, *+## Rejected+*
*lesson*:: *+## What happened+*, *+## Cause+*, *+## Rule now+*
*fact*:: *+## Fact+*, *+## Evidence+*
*retirement*:: *+## Why+*

A section holds 1 to 800 characters. A note with a *migrated* header keeps the
body that *gm import* wrote, and need not follow these sections.

== ANCHORS

An anchor is _COMMIT_:_PATH_, optionally followed by *:*_N_ for one line or
*:*_N_*-*_M_ for lines _N_ to _M_. _COMMIT_ is 7 to 40 lowercase hex characters
that name the commit at HEAD when *gm save* ran. After a squash or rebase
merge, that commit may no longer exist, and *gm* reads the anchor at the
commit that added the note instead. See *gm*(1), *ANCHORS*.
_PATH_ is relative to the repository root and may contain *:*.

When _PATH_ itself ends in *:* or in a part shaped like *:*_N_ or *:*_N_*-*_M_,
the anchor ends with one more *:*, so it reads back as the same path.

== EXAMPLE

----
---
id: 20261114T174452Z-ef6552
type: decision
title: "Cache uses Postgres"
topic: decision/cache-store
keywords: cache store database postgres
at: [3a757f54116a:internal/cache/store.go:10-42]
supersedes: [20261113T100537Z-78bb51]
created: 2026-11-14T17:44:52Z
---
## Decision
Keep the cache in Postgres.

## Why
One database to run.

## Rejected
Redis: another service.
----
